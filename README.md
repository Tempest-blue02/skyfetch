# SkyFetch Weather Dashboard

A weather dashboard application built using JavaScript OOP concepts and OpenWeather API.

## Features

- Current weather data
- 5-day forecast
- Responsive design
- Forecast cards
- Promise.all()
- Constructor functions
- Prototype methods

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API

## Concepts Used

- Prototypal Inheritance
- Constructor Functions
- Async/Await
- Promise.all()
- DOM Manipulation
- Responsive Design
